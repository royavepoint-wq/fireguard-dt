# Step 7 ROI Methodology (Illustrative)

## Disclosure

All ROI values in Step 7 are illustrative project assumptions for academic feasibility analysis.
They are not observed production financial results.

## Currency

Default currency: SGD.

## ROI Formula

Annual ROI:

ROI = (Total Benefits - Total Costs) / Total Costs * 100

Three-year ROI:

3-Year ROI = (3-Year Benefits - 3-Year Costs) / 3-Year Costs * 100

## Payback

Payback Months = Initial Investment / Monthly Net Benefit

Applied only when monthly net benefit > 0.
Otherwise, output is "No Payback Within Model Horizon".

## Cost Assumption Categories

- IoT Sensor Integration
- Edge Gateway / Infrastructure
- Twin Platform Development
- ML Model Development
- Security Hardening
- Training & Emergency Drills
- Annual Cloud / Operations
- Annual Maintenance

## Benefit Assumption Categories

- Avoided Downtime
- Damage Risk Reduction
- Maintenance Savings
- Response Efficiency
- False Alarm Reduction
- Compliance / Preparedness Value

## Scenario Sets

- CONSERVATIVE
- BASE
- OPTIMISTIC

Optimistic remains bounded and avoids unrealistic extremes.

## Technical Evidence Link

Experiment-derived technical evidence (for example hazard reduction vs static route) is loaded separately and displayed as context.

Technical evidence is not directly converted to money without explicit assumptions.

This preserves a strict separation between:

- measured_simulation_metrics
- illustrative_financial_assumptions
