# FireGuard DT - Final Demo Script (3-5 Minutes)

## Primary Live Flow

### 1) Open Command Center (Normal State)

Presenter says:
"We start from a normal building state with all twins online and no active emergency."

Action:
- Open / route.
- Point to risk NORMAL and ready resources.

Highlight:
- Shared 3D Spatial Model and top KPIs.

### 2) Run Full Demo

Presenter says:
"Now I run the standard electrical fire scenario at accelerated speed."

Action:
- Click RUN FULL DEMO.
- Set speed to 5x.

Highlight:
- Timeline begins with anomaly and prediction progression.

### 3) Show Predictive Progression

Presenter says:
"The ML model escalates from warning to critical as sensor evidence strengthens."

Action:
- Briefly open /prediction or point to intelligence panel.

Highlight:
- Predicted class and confidence.
- Synthetic Training Dataset disclosure.

### 4) Explainable AI

Presenter says:
"The explanation panel shows which features increased risk and whether sensor patterns are physically consistent."

Action:
- Open /explainability or use command-center summary.

Highlight:
- Top contributors.
- Physical consistency status.

### 5) 3D Hazard and Route Recalculation

Presenter says:
"As corridor risk changes, evacuation routes are recalculated from live twin state."

Action:
- Keep focus on 3D panel.
- Optionally switch camera preset to Evacuation.

Highlight:
- Hazard overlay.
- Route and occupant movement.

### 6) Response Dispatch

Presenter says:
"Emergency Response Twin dispatches drone and crew with measurable response timing."

Action:
- Point to response summary and timeline.

Highlight:
- First dispatch and first response timing.

### 7) Governance Checkpoint

Presenter says:
"For responsible autonomy, this action pauses for human approval."

Action:
- In manual mode: wait at approval checkpoint.
- Click approve.

Highlight:
- Governance state changes from PENDING to APPROVED.

### 8) Containment and Resolution

Presenter says:
"After approval, containment and resolution complete, and we capture final metrics."

Action:
- Let run complete.

Highlight:
- Outcome quality, containment time, resolution time.

### 9) Scenario and ROI Comparison

Presenter says:
"Finally, we compare strategy outcomes and projected business impact."

Action:
- Open /scenarios then /roi.

Highlight:
- Static vs Shortest vs Twin Optimized.
- Governance branch difference.
- Projected 3-Year ROI scenarios.
