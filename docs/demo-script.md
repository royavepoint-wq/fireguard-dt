# FireGuard DT Demo Script

Target duration: 3-5 minutes.

## Goal

Demonstrate one coherent end-to-end incident lifecycle across all four digital twins, AI prediction, explainability, dynamic evacuation optimization, response coordination, governance, and final impact metrics.

## Recommended Live Flow

1. Open Command Center in normal state.
2. Confirm baseline KPIs: Fire Risk NORMAL, Occupants at Risk 0, Safe Exits available, Response READY.
3. Open Presentation Mode.
4. Select Demo Mode MANUAL APPROVAL.
5. Click RUN FULL DEMO.
6. Narrate anomaly and risk progression in timeline and stage indicator.
7. Highlight Predictive Intelligence and Explainable AI summary (confidence + top contributors + physical consistency).
8. Show 3D hazard overlay and affected infrastructure context.
9. Show evacuation route update and recommended strategy.
10. Show response dispatch status and first-response ETA.
11. Pause at governance checkpoint (HUMAN APPROVAL REQUIRED).
12. Approve the action and continue.
13. Show containment and resolved end state.
14. Review Scenario Complete metrics panel.
15. Open Scenario Lab and show strategy comparison.
16. Open ROI & Analytics and show evaluation/provenance distinction.
17. Export Results JSON and Export Results CSV.

## Presenter Notes

- Keep terminology consistent:
  - Fire & Environment Twin
  - Building Infrastructure Twin
  - Occupancy & Evacuation Twin
  - Emergency Response Twin
  - AI / Decision Orchestrator
  - Shared 3D Spatial Model
- Distinguish evidence sources clearly:
  - MODEL_TEST_RESULT
  - SIMULATION_RESULT
  - ILLUSTRATIVE_ROI
- Remind audience this is an academic prototype and not safety-certified for real deployment.

## Reliability Rehearsal Checklist

Run the complete demo three times before presentation:

1. RESET DEMO restores baseline each run.
2. RUN FULL DEMO starts correctly.
3. MANUAL APPROVAL pauses at governance.
4. Approve resumes flow.
5. Scenario reaches RESOLVED and emits final summary metrics.
